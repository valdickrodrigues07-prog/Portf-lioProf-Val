Site pessoal em formato de landing page única, com estética de terminal, que reúne minha
trajetória entre a sala de aula (Microlins) e o desenvolvimento full stack.

## 🧭 Sobre

Sou desenvolvedor full stack e também atuo na área pedagógica da Microlins, ajudando pessoas
a desenvolverem comunicação, organização e habilidades de tecnologia. Este site reúne minha
formação, meus projetos e as ferramentas que uso no dia a dia — tudo com uma cara de terminal
Linux, que é onde resolvo a maior parte dos meus problemas.

## ✨ Funcionalidades

- **Página única** com navegação por âncoras: sobre, formação, trabalhos, skills e contato
- **Terminal interativo** (easter egg) acessível pelo botão flutuante `>_`, com comandos como
  `whoami`, `skills`, `projetos`, `contato`, `curriculo`, `resumo`, `him` e `help`
- **Alternância de idioma PT-BR ⇄ EN** direto pelo terminal, com o comando `idioma`
  (também aceita `idioma pt` / `idioma en`) — a preferência fica salva no navegador
- **Formulário de contato**, que abre uma mensagem pronta no cliente de e-mail padrão
- Tema dark, animações leves e layout responsivo para celular

## 🛠️ Tecnologias

- HTML5
- CSS3 (variáveis, Grid/Flexbox, animações)
- JavaScript puro (vanilla), sem frameworks
- Google Fonts — Space Grotesk & JetBrains Mono

## 📁 Estrutura

```
├── index.html   → estrutura e conteúdo das seções
├── style.css    → tema, layout e responsividade
└── script.js    → terminal interativo, i18n e interações
```

## 💻 Terminal interativo

Clique no botão flutuante no canto da tela e escolha **Terminal**. Digite `help` para ver a
lista de comandos disponíveis, ou `idioma` para trocar o site entre português e inglês.

## 🌐 Como rodar localmente

```bash
git clone https://github.com/valdickrodrigues07-prog/Portf-lioProf-Val.git
cd Portf-lioProf-Val
```

Depois é só abrir o `index.html` no navegador (ou usar uma extensão tipo Live Server).
