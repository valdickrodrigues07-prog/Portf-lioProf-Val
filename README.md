# Valdick Portfolio

## Estrutura

```text
valdick-portfolio/
├── public/
│   ├── index.html
│   ├── style.css
│   └── script.js
├── server/
│   └── server.js
├── .env.example
├── .gitignore
├── package.json
└── README.md
```

## 1. Instalar

Tenha Node.js instalado e rode:

```bash
npm install
```

## 2. Configurar

Copie:

```text
.env.example
```

para:

```text
.env
```

## 3. Rodar

```bash
npm start
```

Abra:

```text
http://localhost:3000
```
